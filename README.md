# Open Model Weights

**The independent registry for open-weight AI models.**

Current public registry: **107 model records**.

Model Detail 2.0 tracks:
- Weights
- License
- Hardware estimates
- Formats
- Lineage
- Training assets
- Sources
- Verification history

Verification is intentionally split into `verified` and `source-linked` records so broad indexing does not masquerade as field-level verification.

- Website: https://openmodelweights.com
- Models: https://openmodelweights.com/models/
- Registry: https://openmodelweights.com/registry.json
- Methodology: https://openmodelweights.com/methodology/
