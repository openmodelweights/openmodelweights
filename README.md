# Open Model Weights

**The evidence layer for open-weight AI.**

Current public registry: **700 field-verified model records**.

Open Model Weights tracks current model evidence and, from observed states forward, builds durable intelligence that becomes more useful over time:

- exact weight artifacts and repository revisions
- licenses and commercial-use classifications
- context, formats, precision and runtime signals
- model lineage and training/data disclosure
- weight-only hardware estimates
- versioned evidence snapshots and field-level model diffs
- a structured compatibility graph
- a reproducible deployment benchmark protocol
- versioned JSON APIs and a public read-only MCP endpoint

## Evidence principle

The project does not backfill historical claims it did not observe. The evidence ledger starts from actual registry states and adds a new snapshot only when structured evidence changes.

Benchmark results are separate from derived estimates. A benchmark is accepted only with an exact model revision, runtime version, hardware environment, reproducible configuration and public raw evidence.
