# Open Model Weights

**The independent registry for open-weight AI models.**

Open Model Weights is a source-first, machine-readable index of publicly available AI model weights.

- Website: https://openmodelweights.com
- Registry: https://openmodelweights.com/registry.json
- Methodology: https://openmodelweights.com/methodology/
- Hugging Face: https://huggingface.co/openmodelweights

## Principles

1. Prefer primary sources.
2. Separate weight availability from license permissions.
3. Do not turn openness into a subjective score.
4. Attach provenance and verification dates to records.
5. Keep the public registry machine-readable.

The website is deployed as static assets on Cloudflare Workers from the `public/` directory.
