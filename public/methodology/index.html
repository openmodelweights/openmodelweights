METHODOLOGY

Source first. Claims second.

A transparent method for describing open-weight models without collapsing every dimension of openness into a single score.

1. What “open-weight” means here

A model is tracked as open-weight when its model weight files are publicly obtainable from an identifiable source, including sources that require acceptance of license terms. Open-weight does not automatically mean open source.

2. Source hierarchy

We prefer sources in this order: official model repository, official license/model card, developer documentation, research paper, then secondary sources. Core fields should be traceable to a primary source whenever possible.

3. No openness score

We do not assign a single numerical “open score.” Instead, each model gets an Open Weight Profile covering weights, access, license, commercial-use wording, source provenance and—over time—training code, data, recipes and evaluation assets.

4. License handling

Recognized licenses such as Apache-2.0 and MIT can be represented with standard identifiers. Custom model licenses are shown as custom terms and users are sent to the authoritative license. Summaries are informational, not legal advice.

5. Verification status

“Source verified” means we checked that the referenced primary repository existed and exposed the described weight artifact/metadata on the stated date. It does not certify legality, safety, model quality or continued future availability.

6. Corrections

The registry lives in public version control. Corrections can be proposed through GitHub so changes are attributable and reviewable.
