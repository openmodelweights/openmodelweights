Protocol rules

  1. No extrapolated or vendor-marketing numbers.
  2. Every accepted result must identify the exact source repository revision and runtime version.
  3. Results from different precisions, quantizations, runtimes or hardware are separate observations.
  4. Weight-only memory estimates from the registry are not benchmark measurements.
  5. Raw command/config and a public evidence artifact URL are required for accepted community submissions.
