What is distiluse-base-multilingual-cased-v1?

OMW evidence review3 Oct 2026

Open Model Weights records distiluse-base-multilingual-cased-v1 as a 0.134734B-parameter text embeddings open-weight model in the distiluse-base-multilingual-cased-v1 family, with Sentence Transformers listed as the developer. The checked source repository provides 16 recognized weight artifacts, format evidence for Safetensors, PyTorch, ONNX and a verified context window of 512 tokens. Values that are not evidenced in the checked sources remain explicitly undisclosed or unknown.

The repository declares Apache-2.0. Commercial use allowed under Apache-2.0 conditions. Open Model Weights reports the checked license evidence and classification; this is not legal advice.

No base model is declared in the checked standard lineage metadata, so Open Model Weights does not infer one. A training recipe and standard training-data disclosure were not found by the current verifier.
