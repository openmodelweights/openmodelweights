What is chronos-t5-tiny?

OMW evidence review3 Oct 2026

Open Model Weights records chronos-t5-tiny as a 0.0083945B-parameter time series forecasting open-weight model in the chronos-t5-tiny family, with amazon listed as the developer. The checked source repository provides 1 recognized weight artifact, format evidence for Safetensors and a verified context window of 512 tokens. Values that are not evidenced in the checked sources remain explicitly undisclosed or unknown.

The repository declares Apache-2.0. Commercial use allowed under Apache-2.0 conditions. Open Model Weights reports the checked license evidence and classification; this is not legal advice.

No base model is declared in the checked standard lineage metadata, so Open Model Weights does not infer one. A training recipe and standard training-data disclosure were not found by the current verifier.
