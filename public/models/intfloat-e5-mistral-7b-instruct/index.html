What is e5-mistral-7b-instruct?

OMW evidence review3 Oct 2026

Open Model Weights records e5-mistral-7b-instruct as a 7.11066B-parameter embeddings / features open-weight model in the e5-mistral family, with intfloat listed as the developer. The checked source repository provides 7 recognized weight artifacts, format evidence for Safetensors, PyTorch and a verified context window of 32,768 tokens. Values that are not evidenced in the checked sources remain explicitly undisclosed or unknown.

The repository declares MIT. Commercial use allowed under MIT conditions. Open Model Weights reports the checked license evidence and classification; this is not legal advice.
