The registry

The project currently tracks 107 records and is designed to separate simple repository discovery from deeper verification of licenses, formats, hardware, lineage and training assets.

Open by default

The public registry remains machine-readable through JSON and a documented schema. The website is one interface over that data.

Independent

Open Model Weights is not affiliated with the model developers listed in the registry. Model names and trademarks belong to their respective owners.
