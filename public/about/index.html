ABOUT

An independent index for the open-weight ecosystem.

Open Model Weights is building a neutral reference layer between model publishers, repositories, developers, researchers and AI agents.

The idea

Model discovery is easy; understanding what is actually available is harder. Weight access, licensing, gated downloads, formats, training assets and model lineage are often spread across multiple pages. Open Model Weights puts those facts into a consistent record and keeps the primary source one click away.

Open by default

The public registry is designed to stay openly accessible and machine-readable. The website is an interface over the same underlying records that can be consumed by software.

Independent

Open Model Weights is not affiliated with the model developers listed in the registry. Model names and trademarks belong to their respective owners.
